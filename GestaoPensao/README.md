
# Sistema de Gestão de Pensão — C#

Aplicação de consola desenvolvida em C# no âmbito da formação de Software Developer do CESAE Digital.

## Funcionalidades

- Listagem de 21 quartos distribuídos por 3 pisos.
- Reserva de quartos com identificação do hóspede.
- Check-in com ou sem reserva prévia.
- Pesquisa de reservas por nome ou identificação do hóspede.
- Check-out e libertação de quartos.
- Validação dos dados introduzidos pelo utilizador.
- Menu interativo para gestão das operações.

## Tecnologias utilizadas

- C#
- .NET 10
- Microsoft Visual Studio

## Conceitos de programação aplicados

- Estruturas de dados (`struct`)
- Matrizes bidimensionais
- Métodos e passagem de parâmetros
- Estruturas condicionais (`if`, `else`, `switch`)
- Ciclos de repetição (`for`, `do...while`)
- Validação de entradas com `TryParse`

## Como executar

### Pré-requisitos

- .NET 10 SDK
- Microsoft Visual Studio ou terminal com .NET CLI

### Instruções

1. Clonar o repositório.
2. Abrir a solução `GestaoPensao.slnx` no Visual Studio.
3. Executar a aplicação através de `Ctrl + F5`.
